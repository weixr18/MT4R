### 编译

```powershell
cd D:\Projects\2024_MN4R\4-MT4R-github\Robot-Control\report
xelatex report.tex      # 连续跑两次，第二次才生成目录与交叉引用
```

- 需要 **TeX Live（含 ctex / xeCJK）**，用 `xelatex`（不是 `pdflatex`）。
- 依赖宏包：`ctexart`、`booktabs`、`tabularx`、`graphicx`、`tcolorbox`、`enumitem`、
  `fancyhdr`、`makecell`、`url`、`hyperref`。
- 版式约定：**图题不超过 15 个汉字**，图的解释一律写在正文里
  （以「如图 $X$ 所示……」关联），不把解释塞进图题。

### 排版约束（改图题/表头前必读）

- 图题一律**纯文本 + 已验证有字形的 Unicode**；不用 `$...$`（折行会切断数学模式）、
  不用 `⚠️ / ε / ⇒ / ⁻¹` 与组合变音符（Microsoft YaHei 缺字形）。
- 宽表用 `tabular` + `p{}` + `\resizebox{\textwidth}{!}{...}`；
  **不要用 `tabularx` 的 `X` 列做宽表**（列数多时 `X` 会被压成一字宽并触发
  `X Columns too narrow`，单元格竖排）。
- 含 `_` / `/` 的长标识符（归档字段、文件路径）用 `\path{...}`，不要用 `\texttt{...}`
  （`\texttt` 不在 `_` 处断行，会溢出版心）。

## 为什么报告单独成文（与 CartPole 的区别）

CartPole（Part VIII）的验证结果**进书稿正文**——插 `imgs/cartpole/` 的图、在章节里回填实测数字。
**本批次不同：验证结果不进 `chap4_*.tex`、不往 `1-MN4R/imgs/` 放图、不回填正文数字。**
报告就是最终交付物，因此它必须**自包含**：读者不看计划、不看日志也能判断
「这 4 个算法验证到什么程度、结论是什么、局限在哪、怎么复现」。

书侧只更新**两处机读性标注**：`2index.tex` 的 `$\dag$` 与 `unfinished_contents.md` 的清单。
